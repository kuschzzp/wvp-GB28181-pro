# WVP 单机 Docker 部署学习手册设计

## 目标

在仓库根目录新增独立的 `deployment-guide/`，为第一次部署 WVP 的使用者提供一套可以从头阅读、逐步操作、独立排错的中文学习资料。

这套资料以一台 Linux 服务器运行 WVP、ZLMediaKit、MySQL、Redis 和 Nginx 为主线。CentOS/Rocky Linux 使用者可以直接跟随主流程；Ubuntu 使用者在涉及软件安装、防火墙和系统服务时使用同节给出的对应命令。

学习手册不与项目 README、数据库迁移手册、开发设计文档混排，也不承担旧系统升级说明。

## 读者假设

读者可能只具备以下基础：

- 能通过 SSH 登录服务器；
- 知道服务器的用户名和 IP；
- 可以复制命令，但不熟悉 Docker、Compose、SIP、RTP 或 NAT；
- 手里有支持 GB28181 的大华、水星或其他品牌设备；
- 希望先完成单机部署，再理解每个配置项为什么这样填写。

文档不能默认读者了解 Linux 目录、端口映射、容器网络、云安全组或防火墙规则。第一次出现的术语必须先用普通语言解释，再给命令。

三个 `.example` 文件只用于讲解，不被 Compose 自动读取，不写入真实密码或可直接用于生产的固定密钥。

## 内容设计

### 1. 架构与基础概念

说明五个容器各自负责什么，浏览器、摄像机、WVP、ZLMediaKit、MySQL、Redis 和 Nginx 之间如何通信。使用 Mermaid 图展示管理请求、GB28181 注册和视频播放三条链路。

解释宿主机、容器、镜像、端口映射、数据挂载、空数据目录、SIP、RTP、RTSP、RTMP、HTTP-FLV 等首次会遇到的词。

### 2. 服务器准备

给出硬件容量建议，但明确并发路数、码率、录像保留时间和转码需求会直接影响资源使用，不能承诺固定服务器能承载固定数量的摄像头。

分别覆盖 CentOS/Rocky 和 Ubuntu 的系统识别、时间与时区、磁盘空间、Docker Engine、Compose v2、Git 和常用诊断命令。软件安装命令以当前官方文档为依据，并保留官方链接和查询日期。

考虑部署地点在中国大陆，服务器准备章节增加独立的“下载源选择”流程，明确区分五条链路：宿主机基础软件源、Docker CE/Compose 软件包、Docker Hub 容器镜像、Dockerfile 构建阶段的 Ubuntu/Debian apt，以及 Maven/npm 依赖。Docker CE 软件包给出清华 TUNA 和中科大 USTC 的可核验替代源；容器镜像不硬编码短期可用的匿名公共代理，优先使用云厂商账号专属加速地址，生产环境推荐把本项目所需镜像同步到自己的 ACR/TCR/SWR 私有仓库。首次 Compose 构建中，WVP 镜像会执行 Maven，Nginx 镜像会执行 `npm install` 和前端生产构建；Maven 复用项目 `pom.xml` 已配置的阿里云公共仓库，同时说明仍可能访问 ECC 等独立仓库，npm 则按当前 Dockerfile 使用 `registry.npmmirror.com`。

国内源必须同时写清服务边界和回退方法。例如，清华/中科大 Docker CE 镜像不是 Docker Hub；中科大 Docker Hub 缓存已经关闭；阿里云 ACR 账号加速器已停止同步最新镜像，`latest` 可能滞后。文档不把“此刻能访问”写成长期可用承诺，每个镜像配置都要有检查命令、恢复前配置和失败后的下一条路径。

### 3. 网络与端口

先让读者填写一张部署参数表：服务器内网 IP、公网 IP、域名、摄像机所在网络、是否经过 NAT、Web 端口、SIP 端口和媒体端口。

分别说明同一局域网、服务器直接拥有公网 IP、路由器端口映射三种场景。区分云厂商安全组、Linux 防火墙和路由器端口转发，明确三者不是同一个东西。

端口表必须根据当前 `docker-compose.yml` 和 `.env` 生成，不把未映射端口写成对外必开端口。CentOS/Rocky 额外说明 SELinux 对 bind mount 的可能影响。

### 4. 配置

逐项解释当前 `.env` 中的每一个变量，包括值由谁提供、填写内网还是公网地址、错误填写的表现，以及哪些值必须长期保存。

说明如何使用 `openssl rand -hex 32` 分别生成两个 pepper。说明初始 Compose 中数据库密码和 ZLMediaKit secret 的实际位置及联动关系，不让新手只改一处后造成服务无法连接。

提供局域网、固定公网 IP 和 NAT 三份无真实凭证的配置示例。

### 5. 首次部署

从获取代码、进入正确目录、检查 `.env`、执行 Compose 静态解析开始，再到构建和启动。解释首次构建耗时、镜像拉取、Maven 打包和三段 MySQL SQL 的执行顺序。

每一步统一使用以下格式：

1. 这一步做什么；
2. 执行命令；
3. 正常结果；
4. 如果不正常先检查什么。

说明初始管理员账号、原始密码登录后自动升级密码摘要的行为，并要求首次登录立即修改密码。文档不把旧 MD5 兼容接口描述成推荐登录方式。

### 6. GB28181 设备接入

使用“平台字段—摄像机字段”对照表解释 SIP 服务器地址、端口、传输协议、域、平台国标 ID、设备国标 ID、认证密码和心跳参数。

分别提示大华、水星界面名称可能不同，不编造特定型号菜单路径。给出注册、目录同步、点播三个阶段的检查办法，并解释“设备在线但通道不在线”和“设备在线但无法播放”属于不同问题。

### 7. 域名、HTTPS 与 NAT

基础部署仍以当前 HTTP Compose 为准。进阶章节说明域名只解决访问名称，不自动解决 SIP/RTP 穿透；HTTPS 推荐在现有 Nginx 之前增加受维护的 TLS 入口，避免直接暴露 WVP 内部端口。

准确说明当前播放票据的安全端口来自 ZLMediaKit 实际上报的 `http.sslport=443`，而不是被注释的 `MediaHttps`；不能把取消该注释写成启用 HTTPS 的办法。提供生产“域名 + 外层 443 TLS”方案，以及只允许在可信隔离局域网中使用的“宿主机 HTTP 80 + ZLMediaKit `sslport=0`”实验方案。提供配置思路、证书续期检查和 WebSocket 反向代理要点，但不会声称当前 Compose 已经自动申请证书。

NAT 章节明确区分信令地址和媒体地址，给出端口映射核对表与双层 NAT、运营商 CGNAT 的识别方法。

### 8. 日常运维与备份

覆盖查看容器、日志、资源占用、启动、停止、重启和配置变更后的重建方式。数据库备份采用容器内 `mysqldump` 导出到宿主机的可检查文件，录像目录和配置目录单独备份。

文档明确：普通重建容器不等于删除数据；不得为了“重新初始化”随意删除 `volumes/mysql/data`。本手册不写跨版本数据库升级流程。

### 9. 故障排查

按症状组织，不按组件堆命令。至少覆盖：

- Docker 或 Compose 安装失败；
- 镜像拉取和 WVP 镜像构建失败；
- MySQL 初始化失败或没有重新执行 SQL；
- WVP 循环重启；
- 页面无法打开、502、登录失败；
- GB28181 设备注册不上；
- 设备在线但没有通道；
- 点播超时、黑屏、只有声音、只有画面；
- 推流或拉流端口不通；
- SELinux、文件权限、磁盘已满和端口冲突。

每个问题给出检查顺序、命令、关键输出和下一步，而不是只列可能原因。

### 10. 验收清单

提供可逐项勾选的部署前、启动后、安全、设备接入、播放和备份检查表。最后给出一张部署参数记录表，方便使用者保存自己实际采用的 IP、端口、域名和备份位置；密码与密钥只记录保管位置，不直接写进表格。

## 准确性和安全边界

- 所有项目路径、服务名、端口、变量和命令以当前仓库文件为准。
- Docker 安装等可能变化的外部操作使用官方来源核验，不复制来源不明的一键脚本。
- 中国大陆下载方案优先引用 Docker、镜像站或云厂商的官方页面；第三方公共代理只能作为风险说明，不能成为默认生产方案。
- 修改 `/etc/docker/daemon.json`、系统软件源或项目镜像名称之前先备份；不能用覆盖式示例抹掉服务器已有的其他 Docker 配置。
- 不执行 WVP 项目，不启动 Compose 业务服务。
- 可以做 Markdown 链接、占位符、路径和命令的静态检查。
- 不提供真实 pepper、JWT 密钥、数据库密码、ZLM secret 或设备密码。
- 不建议关闭防火墙、永久关闭 SELinux或对整个目录执行无边界的 `chmod 777`。
- 涉及删除数据、恢复备份和替换密钥的命令必须先解释影响，并默认以保留数据的方案为主。

## 验收标准

- 读者能从 `deployment-guide/README.md` 找到适合自己的阅读路径。
- CentOS/Rocky 主流程与 Ubuntu 差异都有可复制命令。
- 宿主机软件源、Docker CE 软件包、Docker Hub 镜像、容器内 apt 和 Maven/npm 五条下载路径已明确区分；中国大陆路径含来源、适用范围、验证与回退步骤。
- 文档不会推荐已关闭的 USTC Docker Hub 缓存，也不会把阿里云已停止同步最新镜像的账号加速器描述为生产级最新源。
- 三种网络场景均有参数示例和端口判断方法。
- `.env` 每个现有变量都有解释，示例不包含真实凭证。
- 首次启动、首次登录、设备注册、目录同步和点播都有明确的正常结果。
- 常见故障具备按顺序执行的排查步骤。
- 文档不与旧库升级混淆，不承诺未经验证的性能数字或品牌菜单路径。
- 文档内部链接有效，不含未完成章节或未解释占位符。
- 不修改项目现有 README 来混入本学习资料。
